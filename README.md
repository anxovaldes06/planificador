## inicializar el proyecto 

```
npm init
```

## Descargar una dependencia desarrollo(vite)
```
npm i -D vite
```

## Descargar una dependencia de producción (dayjs)
```
npm i dayjs
```
## Probar la app en modo local ( desarrollo )
```
npm run dev
```
## Construir la app
```
npm run build
```
